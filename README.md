# VÉSPERA — site demonstrativo

Landing page cinematográfica responsiva para uma hamburgueria premium fictícia.

## Abrir

Abra `index.html` no navegador. Para as animações, fontes e estilos do GSAP carregarem, o navegador precisa ter acesso à internet (GSAP e Google Fonts são incluídos por CDN).

## Conteúdo

- Identidade tipográfica, conceito, textos e cardápio fictícios.
- Abertura com três momentos de texto, zoom e progresso vinculados à rolagem.
- Parallax e revelações de conteúdo com GSAP + ScrollTrigger.
- Layout responsivo e suporte a `prefers-reduced-motion`.
- Imagens fornecidas pelo usuário em `assets/img/`; fontes listadas em `assets/img/SOURCES.md`.

Os preços, o endereço e o e-mail `.example` são demonstrativos. Atualize os dados antes de publicar ou aceitar reservas.
